# 女朋友评价系统 💕

> 每天只能打一次：**好评 👍 / 差评 👎**，可备注具体原因。
> 一份数据，两个人共享——她打分，你围观。

## 功能

| 页面 | 作用 |
|---|---|
| **今日评价** | 选 好评/差评 + 填备注（选填），每天限一条，可覆盖修改 |
| **历史记录** | 全部评价按日期倒序，顶部好评/差评/总天数汇总 |
| **成绩单** | 好评率环形图、连续好评、最近 14 天热力格、本月统计、**导出图片成绩单** |
| **月报** | 按月翻看：本月好评率、整月日历热力图、高光时刻 / 翻车现场 / 小作文奖 |

**「每天只打一次」怎么保证的？**
用 `日期字符串` 当数据库文档 `_id`（如 `2026-09-22`），写入走 `doc(id).set()`。
`set` 是 upsert 语义：一天之内永远只会存在这一条记录，重复提交 = 覆盖当天评价，
天然不会出现「一天两条」，无需任何额外校验。

## 部署步骤（约 10 分钟）

### 1. 注册小程序
到 <https://mp.weixin.qq.com> 注册**小程序**（个人主体即可，免费）。
拿到 **AppID**。

### 2. 开通云开发
用**微信开发者工具**导入本目录 → 顶部点击「云开发」→ 开通（有免费额度，两个人用绰绰有余）。
记下**环境 ID**（形如 `prod-xxxx` 或 `your-env-id`）。

### 3. 创建数据库集合
云开发控制台 → **数据库** → 新建集合，名称必须是：

```
ratings
```

### 4. 设置数据库权限（重要！）
选中 `ratings` 集合 → **权限设置** → 选 **「所有用户可读，仅创建者可读写」以外的自定义规则**，
把规则改成：

```json
{ "read": true, "write": true }
```

> 因为评价是**她写、你看**，跨账号读写，用默认的「仅创建者可读写」会导致你看不到数据。
> 该小程序是你们两人私用，且 `ratings` 集合不含敏感信息，放开读写是安全的。
> 如果后续想做登录校验，可改用云函数统一读写。

### 5. 填配置
**`app.js`** —— 把环境 ID 填进去：

```js
wx.cloud.init({
  env: '你的环境ID',   // ← 改这里
  traceUser: true,
});
```

**`project.config.json`** —— 把 AppID 填进去：

```json
"appid": "你的AppID"
```

### 6. 运行 / 发布
- 开发者工具里点「编译」即可预览；
- 两个手机都能用：点「预览」扫码，或「上传」后在 mp 后台提交审核发布（需备案/类目，个人小程序按提示走即可）。

## 数据结构

`ratings` 集合，一天一条：

```json
{
  "_id": "2026-09-22",
  "date": "2026-09-22",
  "type": "good",
  "reason": "今天主动做了饭还洗了碗",
  "updatedAt": "<服务端时间>"
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `_id` | string | 日期 `YYYY-MM-DD`，天然唯一 |
| `date` | string | 同 `_id`，便于排序查询 |
| `type` | string | `"good"` 好评 / `"bad"` 差评 |
| `reason` | string | 备注原因，≤200 字，可为空 |

## 常见问题

**Q: 为什么我看不见她写的记录？**
数据库权限没按第 4 步设置。`read` 必须放开为 `true`。

**Q: 提示 `document.get:fail document does not exist`？**
正常，说明今天还没评价。代码已在 `catch` 里当作「未评价」处理。

**Q: 图片成绩单怎么用？**
「成绩单」页底部点「📷 生成图片成绩单」，会画一张 1500×2400 的 PNG 卡片（好评率环、好评/差评天数、连续好评、最近 14 天热力格），然后选**保存到相册**或**预览大图**（预览里可长按转发给闺蜜/发朋友圈）。
保存到相册需要 `scope.writePhotosAlbum` 授权，拒绝后代码会引导去设置页打开。

**Q: 月报为什么翻不到更早的月份？**
代码会先查最早一条记录的月份，往前翻最多到那里，避免翻一堆空月份。

**Q: 图片在真机上糊了怎么办？**
出图时已用 `destWidth/destHeight = 2x` 超采样。若仍不满意，把 `pages/stats/stats.js` 里 `makePoster` 的 `W * 2` 改成 `W * 3`。

**Q: 想改文案 / 配色？**
文案在 `pages/*/​*.wxml`，配色集中在各 `.wxss` 顶部的色值 `#ff6b81`（主粉）和 `#fff0f3`（背景），全局替换即可。

**Q: 想加图标？**
`app.json` 的 `tabBar.list` 每项支持 `iconPath` / `selectedIconPath`（81×81px PNG），填上即可，不填就是纯文字 tab。

**Q: 记录会不会超过单次 20 条的查询上限？**
不会丢。三个页面都做了 `skip/limit` 分页循环取全量，云数据库小程序端单次上限 20 条已兼容。
