# UI 视觉检查 · 2026-09-27

## 发布前复验

`ff72527` 的高清背景及竖版全屏欢迎页再次通过 13 个状态 × 3 种屏宽的 39 项 Playwright 布局检查。当前自动化测试为 83 项通过。欢迎页、回顾页截图及真机待办见 [发布验收记录](RELEASE-VALIDATION-2026-09-27.md)。以下 74 项测试数据为此前 UI 改版时的历史记录，不代表当前测试数量。

本次使用 Playwright CLI 检查由 WXML/WXSS 转换的浏览器预览。测试数据为本地构造数据，没有读取云端用户记录。

## 检查范围

13 个状态分别在 320、390、430 px 宽度下检查，共 39 组：绑定欢迎页、邀请页、绑定成功、首页、记录编辑、日常列表、有记录月历、空月历、我们、首页错误、手动输入邀请码、共同约定、心意券。

最终未发现横向溢出、按钮文字裁切、未加载图片或首页主卡与想念按钮重叠。圆形按钮和日期按钮的宽度与页面定义一致；关键页面同时进行了截图复核。

## 发现并修复

- 预览转换器错误替换了 `.journal-page`、`.month-story-image` 等类名，原有截图的边距和封面高度因此失真。现已将转换限定为元素选择器。
- 微信基础库 3.14.3 和 3.16.2 的 v2 样式包含 `wx-button:not([size=mini]){margin-left:auto;margin-right:auto;width:184px}`。补入这条真实规则后，复现首页评价按钮溢出和邀请码裁切。页面现使用 `button.<class>` 显式定义需要的宽度和边距。
- 绑定页的 `<br/>` 改为小程序原生 `view` 分行。
- 月份或日期筛选切换时清空旧列表与分页游标，避免新筛选请求失败后仍展示、操作旧筛选的记录。月份切换同时清空旧统计；同月切日期保留已有月度标记。

源码检查通过，74 项自动化测试通过，包含月份加载失败和日期筛选失败的回归场景。

## 验证边界

浏览器预览用于检查布局，不能等同于微信真机验收。原生导航栏、键盘、分享面板、订阅授权、云端数据与页面完整交互仍需在微信开发者工具或真机验证。
